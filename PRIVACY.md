# Privacy Policy for Frontend Audit Extension

Frontend Audit Extension analyzes the currently active webpage locally in the browser to provide SEO, accessibility, image, and page structure audit results.

## Data handled by the extension

The extension may read webpage content such as page title, meta description, headings, links, and image alt text for the purpose of generating an audit report.

The extension may store recent audit history locally in the browser using Chrome Storage API. This may include the page URL, hostname, audit timestamp, audit scores, and issue results.

## Data sharing

Frontend Audit Extension does not send, sell, transfer, or share user data with any external server or third party.

## Remote code

The extension does not use remote code. All code is included in the extension package.
